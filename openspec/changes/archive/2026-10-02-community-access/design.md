Repository Chronicleaf only. Primary boundary src/Chronicleaf.Application/Access/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/community-access/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: community-persistence. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Api/AccessEndpoints.cs: POST /api/session {accessToken} → 204 plus HttpOnly SameSite=Strict session cookie; DELETE /api/session → 204 revoke; GET /api/session → {authenticated:true,actorId}. Configure Chronicleaf__AccessTokenHash as SHA256 hex of a random operator-supplied token (minimum 32 random bytes); plaintext token is never persisted. Add session table(id_hash,actor_id singleton,expires_at,revoked_at). Idle timeout 12h, absolute 7d; cookie Secure outside explicit localhost Development. React Settings/SessionGate.tsx offers local login and logout; no multi-user signup.

### Stable owner identity
Add installation.owner_actor_id UUID via this package migration, generate it once for the singleton installation and retain across token/session rotation. Session table actor_id must match this stored value. Hash comparison uses constant-time bytes; session opaque token is32 random bytes and stored as SHA256. Antiforgery value is separate from login token, scoped to session, and its metadata response is owner-only.

## Behavioral model and invariants
All private /api routes require authenticated owner, except /api/health, /api/ready and POST session. Mutations require Origin matching Chronicleaf__PublicOrigin and a per-session antiforgery token returned by GET /api/session. Public Journey routes are enabled only by their owning package. Five failed login attempts per client in 15 minutes returns 429; network exposure requires TLS through deployment configuration.

## Failure, boundary and rollback policy
Missing token hash prevents non-development startup; invalid login returns 401 generic invalid_credentials. Raw token/cookie never appears in logs. Bootstrap setup is operator configuration, never a first visitor claim. Changing the configured hash revokes all sessions on startup. Session rotation updates hash and deletes old cookie. Downgrade never removes access checks.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
WebApplicationFactory + DB: anonymous project calls return 401, valid owner cookie works, cross-origin POST 403, expired/revoked session 401, simultaneous invalid logins throttle at five; browser login/logout keyboard flow and cookie flags checked.

Create CommunityAccessTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CommunityAccessTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/community-access.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: MVP. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts. External artifact/credential/network absence is recorded as prerequisite unavailability; never fabricate success.
