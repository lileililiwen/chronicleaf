Primary boundary src/Chronicleaf.AI/Contracts/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/llm-provider-contract/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: credential-vault, background-jobs, voice-profiles, milestone-evidence. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Application/AI/ILLMProvider.cs: Task<GenerationResult> GenerateAsync(GenerationRequest request,CancellationToken ct). Request {requestId,scopeId,providerId,model,credentialRef?,systemInstruction,untrustedEvidenceJson,responseSchema,maxOutputTokens,timeoutSeconds}; Result {status completed|refused|invalid|failed,text?,providerRequestId?,inputTokens?,outputTokens?,finishReason,errorCode?}. Capability descriptor {id,structuredOutputSupport,nativeJsonSchema,localEndpoint,requiresCredential}. GET /api/ai/providers lists configured and supported separately; POST /api/settings/ai {providerId,model,credentialRef?,endpointRef?}. Five adapters each own transport; no hard-coded default model availability.

### Consent handshake and revision binding
POST /api/milestones/{id}/generation-preview {providerId,model,evidenceRevision,voiceRevision,selectedEvidenceIds,narrativeSelection?} returns {previewId,consentHash,inputEvidenceIds,redactions,providerId,model,credentialRevision,evidenceRevision,voiceRevision,expiresAt}. Owner sees the redacted payload and authorizes it through the subsequent draft/adaptation request carrying consentHash. Server stores generation_previews(id,scope_id,milestone_id,snapshot_json,sha256,expires_at); TTL15min, no raw credential; SHA256 canonical JSON includes provider/model/credential metadata revision, evidence/voice revisions and selected narrative ids. ConsentHash is scope-bound, not bearer auth; changed or expired preview yields409 consent_stale, foreign preview404. Adapters get only server-resolved GenerationRequest. Narrative attachment field stays empty until narrative-memory exists. Provider test doubles registered only in test DI; production settings cannot choose them.

### Multi-asset consent compatibility
POST /api/generation-previews is the generic owner-only preview endpoint; milestone-specific generation-preview is its MVP alias. Shape includes purpose (milestone-story|asset-adaptation|client-report|narrative-summary), aggregateRef, selected bundle ids/revisions, source asset ids/revisions, voice snapshot hash, narrative selections, response schema version and the complete redacted input hash. Only milestone-story purpose is enabled until its owning extension is installed. Every derivative/report/memory request is bound to its exact purpose/source/input hash, not reuse unrelated milestone consent. Preview can aggregate multiple projects only when the actor is permitted on every source and the owning Agency client contract agrees. The provider request is built from the saved preview bytes, not fresh database reads after consent.

## Behavioral model and invariants
Text-only MVP, no tools/function execution or autonomous browsing. Before call, owner authorizes a preview of included evidence ids/redactions/provider/model by consentHash; request frozen to evidence/voice/credential revisions. Default 4096 max output tokens, 120s timeout, input UTF-8 256KiB. Provider result is never approval or milestone state. Unsupported JSON schema falls back to prompt+strict local validator, never a claimed native capability. Transport mock provider exists only in tests, not fake runtime success.

## Failure, boundary and rollback policy
Missing credential/config 422; timeout yields generation_timeout, 401/403 credential_rejected, 429 rate_limited, refusal provider_refused, malformed result provider_invalid_response. Cancel aborts request and suppresses result. Retry only bounded explicit transient pre-response failures; ambiguous billed timeout requires manual regeneration to avoid accidental duplicate spend. Never log system/evidence text by default; audit ids/hashes only.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Contract suite shared by all adapters: fixture completion/refusal/empty/invalid/429/cancel, capture every outbound payload and assert no tools, unknown models surfaced without invention; consent change prevents transport call and no draft approval fields mutate.

Create LlmProviderContractTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~LlmProviderContractTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/llm-provider-contract.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
