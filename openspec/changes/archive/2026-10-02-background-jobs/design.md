Primary boundary src/Chronicleaf.Infrastructure/Jobs/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/background-jobs/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: community-persistence, community-access. ## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Adopt Platform.Jobs 0.1.0 contracts through package restore, add HangfireJobDispatcher:IJobDispatcher backed by Hangfire with PostgreSQL storage in the same database, schema hangfire. Application/Operations defines operation(id,scope_id,kind,target_id,input_revision,idempotency_key,status,attempt,heartbeat_at,error_code,result_ref) and IOperationHandler.HandleAsync(OperationRef,ct). POST /api/operations/{id}/cancel, GET /api/operations/{id}; React OperationsPanel reports queued/running/succeeded/failed/cancelled/superseded. IJobDispatcher payload includes only operationId; no credentials/evidence. Private Hangfire dashboard disabled by default.

## Behavioral model and invariants
Transaction inserts operation+outbox; outbox dispatcher enqueues then marks dispatched; replay may enqueue twice but worker claims conditional queued/retry lease once. Unique(scope_id,kind,idempotency_key) returns original operation on identical payload, conflict on mismatched payload. Maximum three attempts with 5s/30s backoff for explicit transient errors; 429 may use capped Retry-After ≤300s. Cancellation is cooperative plus result suppression. Timeout default 120s, capture 45s, exports 120s. Lease 180s with 15s heartbeat; expired lease recoverable once by conditional update. Providers never own operation state.

## Failure, boundary and rollback policy
No automatic retry of ambiguous external publication writes; publisher contract owns reconciliation. Permanent validation/auth errors fail immediately. Successful worker commits result ref and status atomically; stale input is superseded, no overwrite. Stop/restart cannot claim success without committed result. Clock injected. Package adoption blocks if exact verified Platform.Jobs artifact unavailable; no absolute ProjectReference.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
PostgreSQL + real Hangfire test: stop between enqueue and dispatch acknowledgement, restart, assert one result; two workers contend; cancel while provider waits; stale input yields superseded; transient failure reaches exactly three attempts and permanent failure one.

Create BackgroundJobsTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~BackgroundJobsTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/background-jobs.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
