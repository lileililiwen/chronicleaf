## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Chronicleaf.Publishers/DevtoPublisher.cs implements IPublisherAdapter; target DTO contains platform id, origin/repository/publication as described, credentialRef and revision. Api PUT /api/publisher-targets/devto/{id} validates target configuration; use shared publisher UI. Use Forem POST https://dev.to/api/articles with api-key and Accept application/vnd.forem.api-v1+json; article {title,body_markdown,published:boolean,tags,canonical_url?}. Mode draft sets published=false; publishing true only with explicit reviewed confirmation. Credential per target, maximum4 tags as internal validated bound until provider reports support. Read id/url into receipt. Official reference checked 2026-09-30: [Dev.to reference](https://developers.forem.com/api/v1).

## Behavioral model and invariants
Consume immutable ApprovedAssetSnapshot and publisher-contract state/idempotency/approval policy; adapter cannot modify source Content Asset. Preview hash includes target revision and transformed content, so target change requires new confirmation. Private source metadata excluded; only reviewed content/media may leave the app.

## Failure, boundary and rollback policy
Remote create has no assumed reliable idempotency: timeout unknown, manual reconcile by owner article list/canonical URL and stored hash; duplicate prevention local before send. 401 credential_rejected,422 invalid_platform_payload,429 bounded pre-send wait only; never retry unknown create. Removing target prevents future dispatch but does not delete or retract existing upstream posts. No credential-gated live provider writes during planning; activation requires demand and explicit operator configuration.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Dev.toPublisherTests capture outbound request for draft/publish modes, enforce target/credential scope, upstream 401/422/429, branch/content conflicts as applicable and ambiguous-write receipts. End-to-end private mock target verifies no write before confirmation and one attempt for duplicate input. Real provider round trip requires explicit reviewed target action and records remote receipt separately.

Create PublisherDevtoAdapterTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~PublisherDevtoAdapterTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/publisher-devto-adapter.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
