# Design: Version comparison and evolution image artifacts

## Context and implementation boundary
Repository Chronicleaf only. Primary boundary src/Chronicleaf.Application/Evolution/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/screenshot-evolution-images/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: screenshot-curation, markdown-review-export. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Language, ownership and release
C# net10.0 / ASP.NET Core 10 for Api/Application/Infrastructure/integrations; React + TypeScript + Vite for src/Chronicleaf.Web. PostgreSQL is the single relational store; Hangfire jobs run in application process. Test projects tests/Chronicleaf.Unit.Tests, Chronicleaf.Integration.Tests (real disposable PostgreSQL), and Chronicleaf.Api.Tests (WebApplicationFactory); browser tests under src/Chronicleaf.Web/tests. Interfaces live in Chronicleaf.Application, domain records in Core, IO adapters in the named integration/Infrastructure project, DI in Api/Program.cs. Consumers never reference sibling source directories. Native dependencies pinned in project lockfiles during implementation; no package install or runtime provider call in this authoring task.

**Keep local.** Chronicleaf domain/workflow lifecycle and user review are product-specific; no matching recurring implementation is evidenced in sibling platform contracts. Reuse dependency-owned access/jobs/storage contracts, never duplicate those concerns. Evidence inspected: dotnet-platform-libs/README.md lists Platform.Jobs and Platform.Storage families but no Milestone/narrative/voice/content/publisher workflow. No shared `/lib` added and no sibling edit authorized.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

POST /api/projects/{id}/evolution/images {milestoneIds,layout:before-after|horizontal-timeline|vertical-long|gallery,selectedScreenshotIds,expectedSelectionHash,idempotencyKey} → operation producing PNG artifact and JSON manifest. Choose 2..12 confirmed milestones with explicitly selected screenshots; same viewport group for comparison, user caption/title reviewed as Content Asset. Render using .NET image library behind IEvolutionRenderer, pinned dependency/license verified at implementation, no generative image rewriting. React EvolutionPicker lets owner order milestones and inspect gaps.

## Behavioral model and invariants
Order chronological by occurredAt/id unless owner explicitly chooses manual order stored in manifest. Preserve source pixels using proportional fit and neutral padding, never invent before screenshots. Max rendered40MP/20MiB, each source checksum and revision recorded. Output is a draft visual Content Asset; approval/export follows markdown-review-export gates extended with visual artifact hash. Retained source media references prevent deletion.

## Failure, boundary and rollback policy
Missing media409, mixed viewport422 comparison_viewport_mismatch unless gallery layout, insufficient selected2→422, excessive output413. Captions edited during rendering supersede job. Missing older version is displayed as unavailable, not interpolated. No GIF/video in this package.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Deterministic source PNG fixtures v0.1/v0.2/v1.0 and missing v0.5; assert source pixels/layout ordering, manifest provenance, viewport mismatch error, size cap and approved hash invalidation after selection change.

Create ScreenshotEvolutionImagesTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~ScreenshotEvolutionImagesTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/screenshot-evolution-images.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: POST-MVP. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts. External artifact/credential/network absence is recorded as prerequisite unavailability; never fabricate success.
