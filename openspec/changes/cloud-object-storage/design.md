Repository Chronicleaf only. Primary boundary src/Chronicleaf.Infrastructure/Media/S3/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/cloud-object-storage/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: local-media-storage, cloud-tenant-boundary. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Language, ownership and release
C# net10.0 / ASP.NET Core 10 for Api/Application/Infrastructure/integrations; React + TypeScript + Vite for src/Chronicleaf.Web. PostgreSQL is the single relational store; Hangfire jobs run in application process. Test projects tests/Chronicleaf.Unit.Tests, Chronicleaf.Integration.Tests (real disposable PostgreSQL), and Chronicleaf.Api.Tests (WebApplicationFactory); browser tests under src/Chronicleaf.Web/tests. Interfaces live in Chronicleaf.Application, domain records in Core, IO adapters in the named integration/Infrastructure project, DI in Api/Program.cs. Consumers never reference sibling source directories. Native dependencies pinned in project lockfiles during implementation; no package install or runtime provider call in this authoring task.

**Adopt.** Inspected sibling dotnet-platform-libs/src/Platform.Storage/Contracts/StorageRequests.cs IObjectStorage (UploadAsync/DownloadAsync/GetMetadataAsync/DeleteAsync/PresignAsync), StorageOptions.cs and Local adapter csproj net10.0; README also declares Platform.Storage.S3. Infrastructure → versioned packages; no personal checkout or implicit source hook. Verify restore/build/provider conformance before implementation; unavailable release artifact blocks adoption rather than triggers a duplicate storage interface or sibling edits.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Adopt Platform.Storage.S3 0.1.0 package behind existing IMediaStore/IObjectStorage, configured endpoint/bucket/region/pathStyle/credentialRef by operator; support R2/MinIO/AWS S3 through compatibility checks, not simultaneous credentials or assumed feature equivalence. No ambient metadata credential retrieval. Keys retain scopes/{scope}/projects/{id}/media/{id}. Owner-private API streams or issues scoped GET presign≤5min only after auth; public Journey uses separately reviewed public projection, never promote entire bucket.

## Behavioral model and invariants
Storage mode Local|S3 selected per installation and media migration tool records copied checksum/source key/target key/state, supports restart and verifies before switch. DB/media record schema unchanged beyond providerId and migration status. Upload DB-orphan compensation inherited; deletion only owned unreferenced keys. No tenant chooses arbitrary endpoint/credential or bucket. Local self-host remains dependency-free from S3.

## Failure, boundary and rollback policy
Incompatible provider yields storage_unavailable, checksum mismatch keeps old provider reference. Interrupted copy resumes idempotently, never deletes source until verified migration and operator retention decision. Bucket listing never exposed. Requires exact published Platform artifacts; package unavailable blocks adoption, no sibling edits or source references.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
MinIO container conformance plus captured HTTP fixtures for configured R2/AWS compatibility, key/scope traversal and presign expiry. Copy interruption/restart hash verification, unavailable provider, orphan cleanup and Community Local regression. Real cloud credential run optional explicitly configured.

Create CloudObjectStorageTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CloudObjectStorageTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/cloud-object-storage.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
