## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Application/Capture/IScreenshotProvider.cs CaptureAsync(CaptureRequest{projectId,url,viewport,width,height,waitSelector?,waitMs,fullPage},ct)->CaptureResult{mediaRef,capturedAt,finalUrl,viewport,warnings}. Chronicleaf.Capture/PlaywrightScreenshotProvider.cs uses Playwright .NET Chromium. Defaults desktop 1440x900/mobile 390x844; maximum three URL paths and two viewports per job, wait 0..10s, job 45s, PNG 20 MiB/40MP.

### Candidate schema ownership
This package, not screenshot-curation, creates Core/ScreenshotCandidate.cs and screenshot_candidates table(id UUID,scope_id,project_id,milestone_id,media_id,source_url,viewport jsonb,captured_at,status=candidate,caption='',is_primary=false,revision=1). GET /api/milestones/{id}/screenshots supplies owner-private read-only capture candidates. Candidate creation commits only after verified media ready; tuple(operation_id,url,viewport) unique prevents duplicate job output. Capture does not select, reorder, set primary or append selected evidence. screenshot-curation consumes these records and adds selection behavior/one-primary constraint without redefining capture storage.

### Concrete Linux sandbox execution boundary
Production capture backend is the Linux Community/Hosted image, not a browser with unrestricted host networking. Add src/Chronicleaf.Capture/Sandbox/CaptureSandboxSupervisor.cs and EgressProxy.cs. A narrowly scoped supervisor starts during application-container initialization, runs the fixed packaged Chromium binary as dedicated capture UID2000 with read/write access only to its0700 temporary job directory, and exposes a private Unix socket to API UID1000. The socket protocol StartJob{operationId,nonce,validatedPolicyHash}/StopJob has no arbitrary executable, shell, mount or filesystem-path input; SO_PEERCRED restricts caller UID. Supervisor returns a loopback CDP endpoint for that job, and the .NET provider attaches with Chromium.ConnectOverCDPAsync. Every browser process is killed at cancellation/timeout; no reusable cross-job context.

Root container initialization installs owner-based network rules denying all capture-UID outbound connections except loopback proxy port; Chromium arguments force this proxy, disable QUIC and bypass rules. The application UID can reach PostgreSQL/providers independently. Proxy accepts only authenticated per-job sessions and resolves/revalidates destination at actual connect, pins the socket to validated address, and rejects disallowed CONNECT targets and HTTP redirects/subresources. Thus a direct socket/QUIC/WebSocket/DNS bypass cannot evade policy. Key/media roots remain API-owned inaccessible to browser UID. Container needs Linux CAP_NET_ADMIN for initialization and supervisor UID separation; API itself runs non-root. Native capture outside this sandbox is unavailable rather than a less-secure fallback. Chromium's own sandbox remains enabled; no --no-sandbox default.

Community-compose-release owns packaging/capability declaration for this fixed backend; screenshot-capture owns implementation and Linux sandbox fixture before release integration. If required namespace/firewall support is absent, report capture_sandbox_unavailable and do not navigate. Test direct browser egress, localhost bypass, redirect/rebinding, WebSocket and QUIC attempts against sentinel listeners, not only Playwright route mocks. Scope does not add a third Compose service, separate broker, Python dependency or universal shared security runtime.

## Behavioral model and invariants
Use isolated browser context per job, no saved cookies/login/secrets. URL http/https only, no userinfo, reject metadata/link-local/multicast; resolve and validate IPv4/IPv6 before every connection and redirect. Browser runs inside egress boundary that enforces the same destination rules for subresources, DNS rebinding, service workers and websockets; route interception alone is not the enforcement oracle. Community operator may allow exact origin+resolved address for local preview with explicit expiry, never metadata endpoints. Hosted refuses local-network allowances. Capture candidates not automatically selected/attached into approved evidence.

## Failure, boundary and rollback policy
413 bounds, 422 invalid viewport/URL, 403 capture_target_blocked, 504 capture_timeout; per-page partial outcome allowed with explicit failures and no fake screenshot. Unexpected redirects revalidated, downloads disabled, browser process killed on timeout/cancel. Media write failure fails candidate creation and retires orphan. Browser executable provisioned in container build, never rely on host Python. Deployment image restrictions owned by Compose package.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Real browser test fixture with redirects to private IP, private subresource, rebinding simulation via controlled resolver/egress proxy, websocket, hung page, giant page and desktop/mobile endpoint. Assert blocked traffic never reaches sentinel server and PNG dimensions/hash match; cancellation leaves no linked result.

Create ScreenshotCaptureTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~ScreenshotCaptureTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/screenshot-capture.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
