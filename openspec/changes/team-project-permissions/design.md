Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: cloud-tenant-boundary. ## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Api /api/tenants/{id}/invitations POST {email,role}, accept {token}, members GET/PATCH/DELETE; projects project_memberships(project_id,user_id,permission reader|editor|approver|publisher). Invitation token32 bytes random stored SHA256 TTL7d single-use, email delivery is operator-configured transport and never sent during planning. Owner can manage members; tenant editor can manage only assigned project content; viewer reads assigned. Existing owner implicitly all project permissions. React TeamSettings shows pending invitations and per-project grants.

## Behavioral model and invariants
Explicit policy: reader read; editor create/edit evidence and drafts; approver read+approve/export; publisher read+publish approved asset only; owner all. Roles can combine project grants. Editors cannot approve unless approver granted; publisher cannot skip approval. Last tenant owner cannot be removed/demoted. Revocation cancels future scoped operations and invalidates authorizations at execution, retained approved history preserves actor id. Optimistic membership revision and audit all grants.

## Failure, boundary and rollback policy
Wrong email identity/expired token410, reused token409, foreign tenant404, unauthorized role change403, last-owner conflict409. Invite issuance with unavailable email reports pending delivery, not sent; owner may copy invitation link manually. No cross-site accounts or unauthenticated public write roles.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Matrix tests each role against read/edit/approve/export/publish/member endpoints, last owner race, token expiry/replay/wrong identity, revoked queued task and delivery-failure browser state.

Create TeamProjectPermissionsTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~TeamProjectPermissionsTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/team-project-permissions.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
