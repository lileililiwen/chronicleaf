# Design: Scoped filesystem media storage

## Context and implementation boundary
Repository Chronicleaf only. Primary boundary src/Chronicleaf.Infrastructure/Media/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/local-media-storage/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: community-persistence, community-access, projects-and-milestones. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Language, ownership and release
C# net10.0 / ASP.NET Core 10 for Api/Application/Infrastructure/integrations; React + TypeScript + Vite for src/Chronicleaf.Web. PostgreSQL is the single relational store; Hangfire jobs run in application process. Test projects tests/Chronicleaf.Unit.Tests, Chronicleaf.Integration.Tests (real disposable PostgreSQL), and Chronicleaf.Api.Tests (WebApplicationFactory); browser tests under src/Chronicleaf.Web/tests. Interfaces live in Chronicleaf.Application, domain records in Core, IO adapters in the named integration/Infrastructure project, DI in Api/Program.cs. Consumers never reference sibling source directories. Native dependencies pinned in project lockfiles during implementation; no package install or runtime provider call in this authoring task.

**Adopt.** Inspected sibling dotnet-platform-libs/src/Platform.Storage/Contracts/StorageRequests.cs IObjectStorage (UploadAsync/DownloadAsync/GetMetadataAsync/DeleteAsync/PresignAsync), StorageOptions.cs and Local adapter csproj net10.0; README also declares Platform.Storage.S3. Reuse Platform.Storage 0.1.0 plus selected Local/S3 published adapters; Chronicleaf owns authorization/media metadata facade. Infrastructure → versioned packages; no personal checkout or implicit source hook. Verify restore/build/provider conformance before implementation; unavailable release artifact blocks adoption rather than triggers a duplicate storage interface or sibling edits.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Adopt Platform.Storage and Platform.Storage.Local 0.1.0 published artifacts. Reuse Platform.Storage.Contracts.IObjectStorage UploadAsync/DownloadAsync/DeleteAsync/GetMetadataAsync rather than redeclare it. Application IMediaStore wraps this with PutAsync(scopeId,projectId,stream,mime,length,ct)->MediaRef{id,key,sha256,length,mime}, OpenAsync(mediaId,ct), RetireAsync(mediaId,ct). Key generated server-side scopes/{scopeId}/projects/{projectId}/media/{uuid}; user never selects raw filesystem key. DB media(id,scope_id,project_id,key,sha256,size,mime,state,created_at). Chronicleaf__MediaRoot defaults runtime/media, outside wwwroot. GET /api/media/{id} streams owner-authorized PNG/JPEG with nosniff; no directory listing or local file path responses.

## Behavioral model and invariants
Limit 20 MiB per original image; only decoded PNG/JPEG accepted, maximum 40 megapixels. Write via temporary blob then atomically promote; DB registers ready only after upload and SHA256. Failure before DB commit records/reconciles orphan by opaque id; retained referenced media cannot delete (409 media_in_use). Retire marks inaccessible before asynchronously deleting physical bytes, missing deletion is success. Reconciler purges unreferenced temporary media older than 24h.

## Failure, boundary and rollback policy
Traversal, symlink escape and incorrect byte length reject without external file changes; filesystem full/unavailable maps 503 storage_unavailable, unsupported mime 415, limit 413. No presigned public URL for Local adapter. Adoption requires restore/build/conformance with exact artifacts; if unavailable mark package dependency-blocked, not silently copy sibling implementation. Subsequent S3 package changes adapter only.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Storage conformance on temp media directory: truncate/oversize streams, path and symlink escapes, interrupted upload, concurrent reads/deletes, media reference ownership, restart/reconciliation, no writable-wwwroot exposure; compare original image hashes.

Create LocalMediaStorageTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~LocalMediaStorageTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/local-media-storage.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: MVP. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts. External artifact/credential/network absence is recorded as prerequisite unavailability; never fabricate success.
