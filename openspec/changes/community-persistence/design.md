## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Create src/Chronicleaf.Core and Application class libraries and src/Chronicleaf.Infrastructure/Persistence/ChronicleafDbContext.cs (EF Core/Npgsql net10.0). Application depends on Core; Infrastructure implements Application contracts; Api is composition root. Add initial migration for installation(id UUID singleton, schema_version int, created_at timestamptz), audit_events(id UUID, actor_id nullable UUID, action varchar(80), target_id UUID, occurred_at timestamptz, safe_metadata jsonb), and outbox(id UUID PK, kind varchar(80), aggregate_id UUID, revision bigint, payload jsonb, created_at, dispatched_at nullable). Later packages own their tables. ConnectionStrings__Chronicleaf is required; /api/ready returns 200 {status:ready} only for reachable expected schema, otherwise 503 {code:database_unavailable|schema_mismatch}; /api/health stays process-only. Operator runs explicit `dotnet ef database update --project src/Chronicleaf.Infrastructure --startup-project src/Chronicleaf.Api`; no automatic migration on HTTP startup.

### API and migration ownership
Implement Api/Common/ApiErrorMiddleware.cs and Application/Common/ApiError.cs for the common error envelope and validation mapping stated above. Error and revision serialization is an additive API contract from this package, not independently reimplemented by feature adapters. Installation UUID is the initial Community scope id; access package owns stable owner actor id. Create tests/Chronicleaf.Integration.Tests project with disposable PostgreSQL fixture; never use EF InMemory as transactional/readiness evidence. Outbox payload schema is {schemaVersion:1,kind,scopeId,aggregateId,revision,operationId?}; consumers ignore unknown version with explicit unsupported_event rather than execute it.

## Behavioral model and invariants
IUnitOfWork.ExecuteAsync<T>(Func<CancellationToken,Task<T>>, CancellationToken) commits domain writes, audit and outbox together under PostgreSQL READ COMMITTED. Unique outbox (kind,aggregate_id,revision) prevents duplicate events. Use UTC timestamptz and UUID ids; JSON properties camelCase. No API for raw SQL or audit edits.

## Failure, boundary and rollback policy
Invalid configuration fails startup with redacted message; missing DB or schema never silently creates an in-memory store. Versioned forward migrations must preserve existing rows; destructive downgrade requires backup/restore rehearsal, not automatic retry. Transient DB failure returns 503 and rolls back all transaction writes.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Real PostgreSQL disposable database: apply migration twice, write installation/audit/outbox transaction, terminate/restart API and read same ids; inject failure before commit and assert zero partial rows. Disconnect DB and compare /ready 503 versus /health 200.

Create CommunityPersistenceTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CommunityPersistenceTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/community-persistence.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
