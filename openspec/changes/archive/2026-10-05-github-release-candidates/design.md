## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

POST /api/projects/{id}/github-candidates/sync {since,idempotencyKey} polls tags/releases; POST /api/webhooks/github/{connectionId} verifies raw-body HMAC-SHA256 using vault webhook secret and constant-time signature comparison. Persist deliveries(connection_id,delivery_id unique,event,received_at,status) and candidate source key release:{releaseId} or tag:{name}:{sha} or event:{event}:{objectId}:{revision}. Supported webhook events release(published), create(tag), issues(closed), pull_request(closed+merged), star(created thresholds 100/1000). Candidate display includes source and received timestamp.

## Behavioral model and invariants
Deliveries ≤1 MiB, webhook writes only candidate inbox through outbox then returns 202; retries return same receipt. No owner session required on webhook, signature is its authentication; random connection id not sufficient. Events never confirm/create drafts/publish. Poll interval disabled by default and enabled only through scheduled-sync package. Tag/release for same SHA remain separately attributed but UI can link them; dedupe identical provider source key.

## Failure, boundary and rollback policy
Invalid signature 401, malformed 422, unsupported verified event 202 ignored receipt, oversized 413. Archived/disconnected project acknowledges ignored. No webhook secret or raw private payload log. A GitHub App and GraphQL enrichment are separate packages, not prerequisites for REST candidate collection.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Signed fixtures with duplicate delivery, invalid HMAC, merged/unmerged PR, tag release and stars thresholds; assert exactly one candidate per source key, no confirmed milestone/asset/publication and ignored events have receipts.

Create GithubReleaseCandidatesTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~GithubReleaseCandidatesTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/github-release-candidates.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: POST-MVP. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts. External artifact/credential/network absence is recorded as prerequisite unavailability; never fabricate success.
