# Design: Reproducible two-service Community MVP packaging

## Context and implementation boundary
Repository Chronicleaf only. Primary boundary src/Chronicleaf.Infrastructure/Deployment/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/community-compose-release/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: markdown-review-export, llm-openai-adapter, llm-gemini-adapter, llm-anthropic-adapter, llm-openrouter-adapter, llm-ollama-adapter, background-jobs, local-media-storage. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Language, ownership and release
C# net10.0 / ASP.NET Core 10 for Api/Application/Infrastructure/integrations; React + TypeScript + Vite for src/Chronicleaf.Web. PostgreSQL is the single relational store; Hangfire jobs run in application process. Test projects tests/Chronicleaf.Unit.Tests, Chronicleaf.Integration.Tests (real disposable PostgreSQL), and Chronicleaf.Api.Tests (WebApplicationFactory); browser tests under src/Chronicleaf.Web/tests. Interfaces live in Chronicleaf.Application, domain records in Core, IO adapters in the named integration/Infrastructure project, DI in Api/Program.cs. Consumers never reference sibling source directories. Native dependencies pinned in project lockfiles during implementation; no package install or runtime provider call in this authoring task.

**Keep local.** Chronicleaf domain/workflow lifecycle and user review are product-specific; no matching recurring implementation is evidenced in sibling platform contracts. Reuse dependency-owned access/jobs/storage contracts, never duplicate those concerns. Evidence inspected: dotnet-platform-libs/README.md lists Platform.Jobs and Platform.Storage families but no Milestone/narrative/voice/content/publisher workflow. No shared `/lib` added and no sibling edit authorized.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Root compose.yaml defines chronicleaf+postgres only; explicit PostgreSQL major/image digest and matching backup/restore tooling pinned during package lock refresh, no Redis/queue service. App image includes .NET10 published Api/Web and pinned Playwright browser/dependencies. Named volumes database,media; encryption key read-only secret mount, token hash env. .env.example contains names only, no working secrets. Configure DB readiness healthcheck, application /api/ready, TLS reverse-proxy guidance and loopback default host binding. Keep `.standard/` intact; project compose is separate owner-declared file.

### Capture runtime integration
Bundle the screenshot-capture supervisor and its .NET egress proxy into the same application image. Container initialization creates API UID1000/capture UID2000, private key/media ownership and dedicated browser job directories, applies the documented capture-UID egress firewall with CAP_NET_ADMIN, then starts the non-root API alongside the bounded supervisor. Do not disable Chromium sandbox or run webpage processing as root. Compose explicitly declares the capability and documents Linux-only hardened capture; native builds can test domain/API without pretending screenshot sandbox is available. Verify actual blocked network traffic, real Chromium startup and preserved local-preview exceptions. Two application processes are internal to the one application service; no additional Compose service is introduced.

## Behavioral model and invariants
Operator explicit migrate command with backup before upgrade; application cannot overwrite existing data on restart. Hangfire runs in app against same DB. Cloud/S3 absent. Add scripts/verify-community.sh: native API/unit/integration/browser tests, container build, Compose bring-up, readiness and complete GitHub→confirmed Milestone→screenshot→BYOK draft→edit/approve→download smoke on controlled fixtures. docs operator quickstart uses portable paths and explains third-party evidence transfer. All five configured provider transports must pass contract suites; live smoke opt-in per supplied provider.

## Failure, boundary and rollback policy
Missing key/PAT/BYOK selection fails safely with actionable status, not bootstrapped random values. Browser unavailable yields failed capture. Fresh install and backed-up upgrade+restore tested separately. Publication/repository visibility remains user-owned blocker to actual GitHub publication; package may be runtime-verified without pushing. deployable promotion requires all scoped native/container/runtime checks, not OpenSpec validation.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
On clean checkout without siblings, build image; start two services, execute fixture-driven MVP, restart app/DB with volumes and compare ids/media/draft; backup/restore into fresh volumes and rerun read/export. Verify no default exposed job dashboard, credentials in image layers/logs or extra service dependency.

Create CommunityComposeReleaseTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CommunityComposeReleaseTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/community-compose-release.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: MVP-RELEASE. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts. External artifact/credential/network absence is recorded as prerequisite unavailability; never fabricate success.
