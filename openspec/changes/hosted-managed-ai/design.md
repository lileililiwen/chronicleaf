# Design: Opt-in bounded Managed AI execution

## Context and implementation boundary
Repository Chronicleaf only. Primary boundary src/Chronicleaf.Application/ManagedAI/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/hosted-managed-ai/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: cloud-tenant-boundary, llm-provider-contract, team-project-permissions. Each dependency owns its contracts; do not implement an uncompleted dependency inside this package. Preserve forge.yaml, .standard receipts, unrelated files and current_spec.

## Language, ownership and release
C# net10.0 / ASP.NET Core 10 for Api/Application/Infrastructure/integrations; React + TypeScript + Vite for src/Chronicleaf.Web. PostgreSQL is the single relational store; Hangfire jobs run in application process. Test projects tests/Chronicleaf.Unit.Tests, Chronicleaf.Integration.Tests (real disposable PostgreSQL), and Chronicleaf.Api.Tests (WebApplicationFactory); browser tests under src/Chronicleaf.Web/tests. Interfaces live in Chronicleaf.Application, domain records in Core, IO adapters in the named integration/Infrastructure project, DI in Api/Program.cs. Consumers never reference sibling source directories. Native dependencies pinned in project lockfiles during implementation; no package install or runtime provider call in this authoring task.

**Keep local.** Chronicleaf domain/workflow lifecycle and user review are product-specific; no matching recurring implementation is evidenced in sibling platform contracts. Reuse dependency-owned access/jobs/storage contracts, never duplicate those concerns. Evidence inspected: dotnet-platform-libs/README.md lists Platform.Jobs and Platform.Storage families but no Milestone/narrative/voice/content/publisher workflow. No shared `/lib` added and no sibling edit authorized.

## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

AiAccountMode BYOK|Managed is explicit per tenant; BYOK remains unchanged. Managed AI requires operator-selected provider/model from supported adapters and operator-owned credential vault scope. POST /api/tenants/{id}/ai-mode {mode,consentHash,expectedRevision}; tables ai_budgets(tenant_id,month,limit_units,reserved_units,settled_units), ai_usage(operation_id unique,tenant_id,provider,model,input_tokens?,output_tokens?,charged_units,state). Before managed operation reserve configured maximum weighted-token units, after response settle actual usage only when known; unknown stays reservation pending reconciliation. Audit no prompt plaintext.

## Behavioral model and invariants
Quota atomic PostgreSQL update; concurrent calls cannot exceed limit; caller cannot select unlimited model or fetch operator credential. Consent discloses selected provider and managed operation data. Cancel before dispatch releases reservation; ambiguous provider execution keeps held units until operator reconciles, no automatic duplicate paid call. UI displays mode, budget/usage and unknown usage separately. BYOK calls never bill managed budget.

## Failure, boundary and rollback policy
BLOCKED for activation until maintainer sets provider/model, monthly limit, unit weights, operator secret and financial policy (whether free capped service or paid entitlement, unknown-usage settlement rules). No prices/subscription/payment vendor invented. Budget exhaustion429 managed_ai_quota; disabled model422; missing provider key503; no fallback to charging user's key or silently switch mode. Contract tests can verify bounded accounting independently.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
100 concurrent reservations against small budget, provider refusal/unknown timeout, cancellation before/after dispatch, idempotent settle and tenant crossing; assert cap and no operator credential export, BYOK independence. Real cost/provider round trip records usage separately after activation policy resolved.

Create HostedManagedAiTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~HostedManagedAiTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/hosted-managed-ai.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
