## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Chronicleaf.AI/Providers/OllamaProvider.cs implements ILLMProvider and registers id=ollama. Nonstreaming HttpClient POST configured endpoint + /api/chat. No required key; model,messages,stream:false,format schema when enabled,options.num_predict. Read message.content,done,done_reason,prompt_eval_count,eval_count. No model pulling, model installation or shell execution. Configure selected model as user value; no API key/model identifiers embedded in repository. Provider response ≤2 MiB; request version and model capability descriptor recorded with generation result. Settings provider selection reuses contract UI; no separate provider state machine. Source checked 2026-09-30: [Ollama official reference](https://docs.ollama.com/api/chat).

## Behavioral model and invariants
Map into llm-provider-contract result including provider request id when supplied, never expose headers. Scope and consent are checked by Application before transport. Use injected HttpMessageHandler/clock and per-request cancellation; map max-token truncation to incomplete result. Shared contract defaults and retry rules are authoritative. Community endpoint requires explicit operator allowlist of origin and resolved address; local loopback/private model endpoint is permitted only in that list. Hosted local endpoints disabled. Redirects disabled; metadata endpoints always rejected.

## Failure, boundary and rollback policy
401/403 credential_rejected, 429 rate_limited, 5xx provider_unavailable, response limit provider_invalid_response, incomplete output never valid draft. Preserve cancellation and ambiguous timeout policy; provider availability not proven by mocked tests.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Run OllamaProviderTests with captured official-shaped completion, refusal/safety, truncated, malformed, HTTP 401/429/503 and cancellation fixtures through real HttpClient handler. Assert required headers/body and strict result mapping. Optional credential-gated live smoke records provider/model/time only; never required for deterministic contract suite.

Create LlmOllamaAdapterTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~LlmOllamaAdapterTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/llm-ollama-adapter.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
