## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Application/Secrets/ISecretVault.cs defines PutAsync(scopeId,provider,secret,ct)->SecretRef(UUID), ResolveAsync(secretRef,ct)->leased disposable secret buffer, DeleteAsync(secretRef,ct). API PUT /api/settings/credentials/{provider} {value}, GET metadata {id,provider,configured,updatedAt}, DELETE id. Never return secret. Support github/openai/gemini/anthropic/openrouter/ollama/publisher identifiers. PostgreSQL credentials(id,scope_id,provider,ciphertext bytea,nonce bytea,key_version,updated_at,revision) unique(scope_id,provider). AES-256-GCM encrypts with external Chronicleaf__EncryptionKeyFile, 32 bytes, associated data scope/provider/id/version; file restricted to operator runtime, not DB or image. Settings UI accepts and replaces values without loading them.

## Behavioral model and invariants
Only authenticated owner can configure credentials; worker resolves by SecretRef after rechecking scope. Jobs serialize refs, never plaintext. Deletion makes queued jobs fail credential_missing. Rotation replaces encrypted value transactionally; concurrent update uses If-Match revision. Data leaves vault only to its fixed provider transport; logs and exception payloads use provider code, not raw request headers.

## Failure, boundary and rollback policy
Missing/wrong key fails startup/unseal; never generate a fresh key over encrypted data. Empty credential 422, stale revision 409, unrecognized provider 422. Backup includes database and separately protected key; document restore validation. No unsupported claims of secrets never in process memory.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Seed distinctive sentinel PAT/BYOK, inspect DB ciphertext and captured job/log/error/API/export bodies for sentinel absence; correct key decrypts, wrong key fails, deletion prevents HTTP call, concurrent replace returns 409, restore key+DB succeeds.

Create CredentialVaultTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CredentialVaultTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/credential-vault.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
