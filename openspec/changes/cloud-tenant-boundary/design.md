## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Hosted only: configure Chronicleaf__Mode=Hosted and site-specific OIDC issuer/clientId/callback, no shared manager/operator token or cross-site login identity. OIDC authorization-code+PKCE validates state/nonce/issuer/audience/signature; Api issues its local secure session. Tables users(id,issuer,subject), tenants(id,name,created_at), tenant_memberships(tenant_id,user_id,role owner|editor|viewer,revoked_at), scopes(id,tenant_id nullable,installation_id nullable). Community singleton scope remains valid in Community; Hosted requires explicit active tenant and server-derived scope. Provision initial hosted owner tenant through verified login plus explicit create-tenant action, default max1 tenant/account until operator quota configured.

### Scoped descendant migration
For child tables whose scope previously derived from project or asset FK, add/backfill explicit scope_id through the owning parent before enabling NOT NULL and composite foreign keys (scope_id,parent_id). A scope mismatch cannot be inserted even with a guessed UUID. RLS policy includes server-derived tenant context for both SELECT and WITH CHECK mutations. Worker sets scope/tenant via SET LOCAL within every transaction and cannot inherit connection-pool session state. Community install scopes gain nullable tenant_id; Hosted cannot treat a null tenant as global accessible data.

## Behavioral model and invariants
Migrate existing tables by preserving Community scope ids; all domain/credential/media/operation/report queries scoped by authenticated tenant. Add PostgreSQL row-level security for tenant tables and tenant context through transaction SET LOCAL, never session-persistent connection state. Job execution resolves scoped operation via authenticated internal worker and attaches tenant context transactionally. OIDC provider configuration operator-managed; tenant invitations and project ACL separate teams package.

## Failure, boundary and rollback policy
Foreign identifiers404, missing membership403, no active tenant409 tenant_selection_required. Cross-tenant source/secret/media keys denied at both app and RLS; admin cannot bypass through ordinary API. Remove membership revokes sessions/job authorization. Configuration missing/issuer mismatched fails closed. Hosted rollout of an existing Community volume requires explicit migration/import policy and backup, not automatic tenant reassignment.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Two tenant DB/RLS tests on reused pooled connection, guessed API ids, media and credentials, background job replay, OIDC issuer/state/nonce failures and membership revocation. Community snapshot migrates without changed scope; no shared operator auth accepted.

Create CloudTenantBoundaryTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~CloudTenantBoundaryTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/cloud-tenant-boundary.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.
