Primary boundary src/Chronicleaf.Application/Evidence/; domain types in Core, exported service contracts in Application, DbContext configurations/migrations in Infrastructure/Persistence, route mapping in Api, optional UI at src/Chronicleaf.Web/src/features/milestone-evidence/. Inspect the explicit symbols below; create only modules needed for this outcome. Dependencies: projects-and-milestones, local-media-storage. ## Contract and compatibility decisions
Consume the common contracts owned by dependency packages: UUID ids, UTC ISO8601 timestamps, camelCase JSON, owner/scope lookup and optimistic bigint revision. Private routes use community-access owner sessions; Hosted activates cloud-tenant-boundary, then team-project-permissions gates reads/edits/approval/publishing. Absent Hosted packages does not silently enable tenancy. Unknown or foreign-scoped resource is 404; unauthenticated private request 401, insufficient permission 403; malformed JSON400, semantic validation422, missing required If-Match428, stale revision409, oversized payload413, transient dependency503, timeout504. Error envelope is {code,message,traceId,fieldErrors?}; message never includes provider raw bodies, tokens or absolute host paths. The persistence package owns serialization/error middleware; feature-specific error codes named below extend it without changing envelope. Every mutation audits ids/action/revision, not secret/evidence plaintext. List endpoints default25/max100 with scope-bound opaque cursor when applicable. Bound input limits and deterministic empty/missing states appear below.

Core/EvidenceBundle.cs {id,milestoneId,revision,createdAt,items[]}; EvidenceItem {id,kind,sourceRef,sourceRevision,capturedAt,payloadSha256,text,mediaId?,redactions[],availability:complete|partial|unavailable}. Kinds project-metadata/commit/diff/release/issue/pr/screenshot/manual/limitations/next-steps. IAppendEvidence.AppendAsync(milestoneId,expectedRevision,items,ct)->bundle; GET /api/milestones/{id}/evidence; POST /evidence/manual {notes,knownLimitations,nextSteps,expectedRevision}. Immutable bundle rows unique(milestone_id,revision); items scoped and referenced, never overwritten. Import/capture adapters call this service, not write draft text.

## Behavioral model and invariants
Each append creates complete immutable snapshot with predecessor; copies references not image bytes. Canonical JSON hash uses sorted object keys and stable item-id ordering. Keep raw private provenance separately from export allowlist; do not store full diff when limits/exclusions apply. Publish EvidenceChanged outbox event containing milestoneId/revision only; review package uses it to invalidate approval. Unavailable evidence is represented, never an empty false-success source. Manual corrections add a new item with supersedesId.

## Failure, boundary and rollback policy
Foreign project/media refs 404; expected revision stale 409; malformed kind/source 422; duplicate source+revision+hash append is no-op. Max text bundle 256 KiB and 500 items; reject oversize with 413 rather than drop unmarked facts. Referenced previous bundles retained. Prompt injection strings stay untrusted data, not execution instructions.

For new tables use a uniquely named forward EF migration plus schema integration test. Additive changes must preserve preexisting scope/revisions; a required nonnull column is backfilled before enforcement. No destructive rollback by ordinary startup. If this package owns no table (pure renderer/adapter/query), migration is N/A and verify existing schema unchanged. Rollback disables only this feature's registration/configuration and preserves stored evidence/assets/receipts; upstream publication and previously exported bytes are never assumed reversible. Partial IO result state must follow the owning jobs/media/publisher contract, not be called success. Scope/time/revision checks happen again at result commit.

## Verification oracle
Fixture bundle of commit, truncated diff, manual limitation and screenshot; append concurrently and verify one new revision; duplicate no-op; old hash unchanged; foreign media rejected; EvidenceChanged emitted atomically and partial source explicit.

Create MilestoneEvidenceTests in the relevant test project; seed scope A/B, deterministic UUIDs and injected UTC clock where data/state is involved. Assert externally observable response/record/hash/side effects for each scenario, not private implementation structure. Commands: `dotnet build Chronicleaf.sln --nologo`; `dotnet test Chronicleaf.sln --filter FullyQualifiedName~MilestoneEvidenceTests`; frontend UI changes additionally `npm --prefix src/Chronicleaf.Web ci`, `npm --prefix src/Chronicleaf.Web run build`, `npm --prefix src/Chronicleaf.Web run test:e2e -- tests/milestone-evidence.spec.ts`. Required DB/browser/provider fixture services must actually run; unavailable dependency is a failure to record, not a passing mock runtime claim. Configure test projects and native scripts in dependency foundation packages before feature execution. Apply any configured local Gate, then names/strict validation/diff checks.

## Decision ledger and activation gates
Phase: MVP. No unresolved product-policy decision in this scoped contract. Demand-gated packages require recorded demand before activation; Cloud packages do not become Community dependencies unless explicitly indicated for optional tenant-safe extension. Native third-party versions are lockfile implementation inputs, verified against .NET10/toolchain and fixtures, not an invitation to redesign contracts.
